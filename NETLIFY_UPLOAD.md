# Cara deploy ke Netlify

1. Upload/commit isi ZIP ini ke root repository GitHub.
2. Hubungkan repository tersebut ke Netlify.
3. Pastikan `netlify.toml` berada di root repository.
4. Trigger deploy ulang.
5. Hasil build akan dibuat di folder `site/` dan dipublish otomatis.

Halaman root menampilkan tombol 9 simulasi. Saat salah satu simulasi dibuka, yang tampil hanya frame simulasi penuh dengan kontrol parameter di dalam frame.
