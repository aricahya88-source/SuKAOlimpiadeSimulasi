# Praktikum Virtual — Gaya Gesek Bidang Miring

Diagram 2D menggunakan geometri permukaan langsung. Pusat balok dihitung dari titik pada garis miring + normal permukaan dalam satuan skala kanvas, sehingga sisi bawah balok tepat menyentuh bidang. Saat berada di lantai, balok menjadi horizontal dan tetap menempel pada lantai.
