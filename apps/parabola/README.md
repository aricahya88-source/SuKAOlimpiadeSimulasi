# Physics Lab — Praktikum Virtual

Simulasi gerak parabola 3D dengan viewport 16:9. Antarmuka difokuskan pada eksperimen: kontrol parameter, lintasan, skala lantai, jejak, dan pantulan. Bagian tabel data, grafik, dan kesimpulan tidak ditampilkan pada versi ini.

## Menjalankan
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Skala meter mengikuti rentang lintasan. Jejak oranye terbentuk selama gerak, kemudian bola memantul dengan energi visual yang berkurang saat menyentuh lantai.
