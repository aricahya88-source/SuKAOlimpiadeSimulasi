# Praktikum Virtual — Tumbukan

Versi bersih dari simulasi tumbukan: hanya laboratorium 3D berbasis Three.js, tanpa AR, WebXR, kamera, PWA, landing page, atau fitur instalasi.

Parameter awal mengikuti soal simulasi tumbukan: `m1=2 kg`, `u1=6 m/s`, `m2=1 kg`, `u2=0 m/s`, dan `e=0,50` untuk tumbukan lenting sebagian.

```bash
npm install
npm run dev
npm run build
```
