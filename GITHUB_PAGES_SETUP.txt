SETUP GITHUB PAGES - SuKa Olimpiade Fisika

1. Upload/replace seluruh isi repository dengan paket ini.
2. Pastikan file workflow berada di:
   .github/workflows/deploy.yml
3. Buka GitHub repository -> Settings -> Pages.
4. Pada Build and deployment -> Source pilih: GitHub Actions.
   JANGAN pilih Deploy from a branch.
5. Commit/push ke branch main.
6. Buka tab Actions dan tunggu workflow:
   Deploy 9 Simulasi ke GitHub Pages
   sampai job build dan deploy sama-sama hijau.
